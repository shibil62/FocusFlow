## FocusFlow 1.0.0

First public release.

### Highlights
- Calendar with day, week, month and agenda views, drag to create, move and resize
- Deadline intelligence: urgency levels plus a 0 to 100 score that weighs time, workload and priority
- Tasks with subtasks, recurring tasks, categories, search and undo
- Power Mode focus timer that survives closing the app
- Dashboard and analytics, light and dark themes
- Local-first: all data stays on your PC

### Install
Download **FocusFlow-1.0.0.exe**, run it, and follow the installer. Java is included.

Windows may show "Windows protected your PC" because the installer is not code-signed.
Click **More info**, then **Run anyway**.

### Known limitations
Windows only, English only, no cloud sync.
